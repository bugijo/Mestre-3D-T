## Melhorias aplicadas nesta rodada

- Otimizacao do autosave no `AppStore`:
  - remove serializacao sincronizada a cada update de estado
  - serializa/salva no debounce, reduzindo custo na thread principal
  - adiciona tratamento de erro no save assíncrono
- Robustez da simulacao degradada:
  - validacao de nota ajustada para `state: 'attached'`, evitando falso negativo em layout mobile
- Operacao:
  - novo script `npm run test:degraded`
  - guia de testes atualizado com carga multi-mesa e cenarios degradados

## Recomendacoes objetivas

1. Monitorar `initialLoadMs` em rede ruim a cada release para evitar regressao.
2. Considerar prefetch gradual de rotas para reduzir tempo de primeira navegacao em ambiente degradado.
3. Manter `test:load` e `test:degraded` no gate de release para baseline consistente.
